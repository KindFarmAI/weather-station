# KindFarmAI — Метеостанция

Система сбора, обработки и отображения метеоданных для сельского хозяйства.

## Что здесь хранится

- **Прогнозы погоды** — 10-дневные прогнозы по нескольким источникам (Open-Meteo, Яндекс, GFS)
- **Агропогода** — данные для сельского хозяйства (температура почвы, влажность, фазы вегетации)
- **Excel-отчёты** — таблицы с подробными данными и графиками
- **Python-скрипты** — инструменты для скачивания и обработки данных (ERA5, прогнозы)

## Как это работает

1. Через **Zai Chat** я запрашиваю метеоданные
2. Создаю файлы (таблицы, скрипты, отчёты)
3. Автоматически заливаю их в этот репозиторий
4. Файлы синхронизируются в **GitHub Desktop** на вашем компьютере

## Файловая структура

```
weather-station/
├── index.html          — Главная страница метеостанции
├── forecasts/          — Прогнозы погоды (Excel, CSV)
├── agroweather/        — Агрометеорологические данные
├── scripts/            — Python-скрипты для обработки
├── reports/            — Готовые отчёты
└── README.md           — Этот файл
```
